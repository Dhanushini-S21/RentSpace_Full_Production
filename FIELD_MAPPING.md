# RentSpace field mapping

## Owner landing page
### Personal information
- Name
- Age
- Own location
- Current location
- Mobile number
- Aadhar card number (encrypted at rest)

### Rental information
- Rental house location
- Type: 1 RK, 1 BHK, 2 BHK, 3 BHK, Single Room, Single Bed
- Rent
- Advance
- Furnished: No available / Mention items
- Furnished items/type
- Electricity: Separate / Joined
- Bedrooms
- Hall
- Kitchen
- Pooja room
- Bathrooms
- Allowed people: Bachelors, Family, Single men, Single women, Couple
- Minimum/maximum people
- 2-wheeler parking count
- 4-wheeler parking count
- House area size (optional)
- House constructed year
- Facing: 8 directions
- Available: Immediate, Within a week, Specific date, Within a month
- Nearby landmarks
- Rental duration minimum/maximum days
- Other conditions

## Tenant landing page
### Personal information
- Name
- Age
- Native / previous location
- Current location
- Mobile number
- Aadhar card photo

### Rental information
- Purpose: Job, Treatment, Education, Transfer, Others + text
- People: Bachelors, Family, Couple, Single man, Single woman
- Minimum/maximum people
- Property: 1 RK, 1 BHK, 2 BHK, 3 BHK, Single Room, Sharing Room
- Rent minimum/maximum
- Advance minimum/maximum
- Rooms needed
- Rental duration minimum/maximum days
- 2-wheeler parking count
- 4-wheeler parking count
- Needed: Immediately, Within a week, Specific date, Within a month
- Preferred locations
- Preferred landmarks
- Other preferences / conditions

## Admin
Admin dashboard reads all owner profiles, owner property data, tenant profiles, tenant Aadhar photo, and inquiries from database.
